AzusaTrade biquote | GitHub -> Vercel
===================================
1. Ekstrak ZIP ke:
   C:\Users\funka\Downloads\AzusaTrade-Biquote-Update\
   Pastikan ada subfolder azusatrade\ yang berisi package.json dan UPDATE-GITHUB.cmd.

2. Cara termudah: klik dua kali azusatrade\UPDATE-GITHUB.cmd.
   Script otomatis git pull --rebase, Robocopy, commit dan push.
   Tidak memakai force push atau Robocopy /MIR.

3. Manual lewat CMD (perintah satu demi satu):

cd /d "C:\Users\funka\Downloads\azusa-trade-github"
git pull --rebase origin main
robocopy "C:\Users\funka\Downloads\AzusaTrade-Biquote-Update\azusatrade" "C:\Users\funka\Downloads\azusa-trade-github" /E /R:2 /W:2 /XD .git node_modules .next .vercel dist build /XF .env .env.local .env.production .env.development
git rm -f --ignore-unmatch -- server/relay.mjs server/twelve-stream.mjs Dockerfile .dockerignore
git add -A
git diff --cached --stat
git commit -m "Switch Forex to biquote real-time"
git push origin main

Jika tidak ada perubahan, git commit akan melaporkan nothing to commit. Ini bukan error.
Jika git pull gagal atau konflik, JANGAN lanjut push. Jangan gunakan git push --force.

4. Vercel Production: redeploy commit terbaru. API key Twelve Data tidak digunakan lagi.
5. Periksa:
   https://azusa-trade.vercel.app/api/config
   https://azusa-trade.vercel.app/api/history?symbol=XAUUSD&frame=5m&limit=10
   https://azusa-trade.vercel.app/api/price?symbol=XAUUSD

Catatan: sistem ini mengganti Forex dengan biquote tanpa mempengaruhi jalur Binance/OKX.
Pine tetap subset; GoldGuard belum bisa dijalankan penuh dengan runtime yang tersedia.

Seluruh file tidak boleh dipublish jika terdapat data rahasia pribadi; file .env dikecualikan.
