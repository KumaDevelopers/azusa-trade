CARA UPDATE AZUSATRADE GOLDGUARD 180 CANDLE

1. Ekstrak AzusaTrade-GoldGuard-180-Candle.zip ke folder baru.
2. Masuk folder azusatrade hasil ekstrak.
3. Jalankan UPDATE-GITHUB.cmd dari CMD.
   Script otomatis melakukan npm install, validasi batas histori,
   npm test, typecheck, build, lalu push ke repo GitHub lokal.
4. Jika tes gagal, jangan push; kirim pesan error lengkap.
5. Source asli ada di indicators/GoldGuard-Original-12000.pine.

Tidak perlu Dukascopy, SEED-HISTORY-GOLDGUARD.cmd atau file CSV.
Batas histori menjadi 180; semua rumus metode, entry, TP, SL,
BE, trailing, reverse signal tidak diubah. Hasil sinyal mungkin
berbeda akibat histori yang lebih pendek, dan PineTS belum dijamin.
